# Perspectives · 20 native editable clips

Open `/examples/perspective-lab/` on your HocusPocus installation, or choose
**Studios → Video 3D → Shot library → View and rate the 20 new clips**.
The same templates appear under **Perspectives** and **Creative** in the editor.

Each clip is a six-second, 720 × 1280 native World3D export. The compositions
combine separate cutout figures and foreground props with painted environments,
contact shadows and a slow level camera. PSX is applied to individual layers:
characters, props or backgrounds can retain different styles.

Play cards inline or select **Ver en grande**. Only one clip plays at a time.
Mark **Me encanta**, **Retocar** or **Descartar**, add notes and filter the results.
Ratings are stored in this browser on this installation's origin. They are not
synced to the server. **Descargar mis valoraciones** exports a JSON copy, including
unevaluated items, for sharing or backup. Rating a template does not delete it.

**Descargar plano** provides a `.world3d.json` file for **Open shot JSON**.
**Plantilla reutilizable** provides a `.world3d-template.json` file for
**My scenarios → Import scenario**. Assets are bundled with this HocusPocus
collection under `/examples/creative/`; the JSON files are not standalone assets.

`PROVENANCE.json` records the actual MiniMax image requests, completed jobs and
SHA-256 hashes. `RENDERS.json` records native scene/export receipts, durations and
clip hashes. Backgrounds are native HocusPocus Image-01 generations; videos use
HocusPocus's World3D renderer without an AI video generation model.
