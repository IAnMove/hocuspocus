# Living backgrounds · six editable layered compositions

Open `/examples/living-worlds/`, or choose **Studios → Video 3D → Shot library → Living backgrounds**.

Each template has a **static architectural image with real openings**, an independent
**exterior-video** plane behind it, and characters and props at other depths.
The source image is preserved. Window contours live in the scene document and become
holes in its native image-plane geometry. Frames, walls and window mullions stay solid
while the outdoor video moves. Camera parallax and picking use the same geometry.

Select **background → Transparent windows** to draw a contour, save it, drag its
points, edit another pane, or close an opening. Select **exterior-video** to replace
the landscape, move its depth or adjust playback. PSX is independently configurable
per character or prop. Existing still templates remain available.

Six-second portrait previews are native World3D exports at 720 × 1280, 30 fps.
Outdoor-only clips were generated through HocusPocus with the installed MiniMax H3
Fused four-step workflow; their native 544 × 960 files are bundled under
`/examples/creative/*-exterior.mp4`. Scarlet and orchard interiors were generated
with HocusPocus Image-01. These compositions are silent.

The gallery lets you view each exterior video and static image separately. Download
**Plano** for Open shot JSON or **Plantilla reutilizable** for My scenarios → Import
scenario. JSON references the bundled collection assets; it is not a standalone media
package. Ratings are stored in a separate browser key from Perspectives. Download the
JSON report to share or back them up. Only one preview plays at a time.

`PROVENANCE.json` records native generation prompts, jobs, timing and file hashes.
`RENDERS.json` records native composition receipts and decoded-media verification.
