# CPU-only test dependencies — the single source of truth shared by CI
# (.github/workflows/ci.yml) and the Cloud Agent dev environment
# (.cursor/install.sh).
#
# WHY THIS EXISTS
# Loreframe Lab's runtime does two things that CANNOT run on CI or any
# CPU-only box: GPU diffusion/video generation, and Director planning that
# talks to a local llama-server / external LLM. So CI never generates media
# or calls a real model — the test suite drives that logic with stubs and
# tiny fixtures. This file is therefore the subset of app/requirements.txt
# that the tests actually import, pinned to the same versions, MINUS every
# GPU-only wheel (flash-attn, xformers, sageattention, torchcodec,
# onnxruntime-gpu, insightface, …) which needs CUDA.
#
# PyTorch itself is installed separately from the CPU wheel index (see the
# CI job and .cursor/install.sh) because it needs its own --index-url.
