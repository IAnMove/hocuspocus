# Video 2D lettering faces

These files are vendored so the Lab can paint them offline. They are not loaded from a CDN.
Latin covers Western European text, including Spanish. Latin Extended is included where the family ships it.
Permanent Marker has no Latin Extended file in the Fontsource package; characters outside Latin fall back to the next family in the stack.
