# Living Dark Fantasy — twenty editable portals

Open `/examples/dark-worlds/` to play and rate twenty six-second 720 × 1280 compositions. Ratings and notes stay in the current browser and can be exported as JSON. This gallery uses its own storage key, separate from Living Worlds and Perspective Lab.

In HocusPocus use **Studios → Video 3D → Shot library → Dark Fantasy** (or **Living backgrounds**). Every new preset has a static architectural image with an editable opening, a separate animated landscape video, grounded character and foreground cutouts, and a level, gentle camera. Select **exterior-video** to change the moving landscape; select **background → Transparent windows** to edit the opening. PSX is subtle and affects one independent piece only.

The gallery offers the final MP4, the source outdoor-only video, the static architectural image, a scene JSON and a reusable template. All media generation and final composition use HocusPocus's public image/video job APIs and native Video 3D export. `PROVENANCE.json` records source jobs; `RENDERS.json` records native publication and media validation. The installed MiniMax H3 Fused 4-step model generated the twenty distinct outdoor plates; no extra model download is required to play or edit them. Image-01 generated the architecture; holes are saved geometric contours and leave the raster source intact.

The colossal ruins evoke monumental adventure fantasy. They are original generated scenes, not extracted game assets. Clips are intentionally silent visual studies.

The Sleeping Titan uses an exterior segment trimmed with the native Video Editor, played at 0.75× in its screen layer to fill the six-second scene. Its source job and native edit are both recorded in `PROVENANCE.json`.
