TU SIGUIENTE PLANO

El fondo se mueve. Tú diriges.

En HocusPocus: Estudios → Vídeo 3D → Biblioteca de planos → Fondos vivos. Cambia el personaje, selecciona cualquier pieza o ajusta la cámara.

Selecciona exterior-video en la lista de objetos para cambiar el paisaje o su velocidad. Selecciona background → Ventanas transparentes para ajustar los huecos. El marco y las paredes conservan la imagen original; personajes, objetos y PSX se editan por separado.

También puedes descargar el plano y usar Abrir plano JSON. La Plantilla reutilizable se importa desde Mis escenarios.
