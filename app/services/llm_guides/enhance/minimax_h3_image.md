# MiniMax H3-Image, text to image

Describe the finished picture in one paragraph. The reader should see the image, not a list of edits.

- Name the subject and the action first, then the layout, then the style and the small details.
- Write the description in English. Words printed inside the picture stay in their own language and are written in quotes.
- If the picture has no writing, say: the image contains no text.
- Do not mention a file format, a seed, a step count, an aspect ratio, or a request to upscale.
- The studio sends an exact width and height. The usual canvas is 2048x2048. Ask for 4096x4096 only when the shot needs it.
- A short prompt may stay in the user's language. MiniMax expands a text-to-image prompt unless expansion is turned off.
