# MiniMax H3-Image, edit with references

The first attached picture is Picture 1, the picture being changed. The next pictures are Picture 2, Picture 3, and so on, in the order they were attached. Use at most 16.

- Give each picture a role: the scene to change, a person's identity, a style, or an object.
- Say what stays and what changes. Describe the finished picture, not a command such as "make it better".
- Quote every word that must appear. If the picture has no writing, say: the image contains no text.
- Write the description in English. Quoted words inside the picture stay in their own language.
- MiniMax expands edit prompts. Do not translate the user's prompt before it is sent.
