# H3-Image frame with references

Picture 1 is the frame being continued or changed. Each later reference is Picture 2, Picture 3, and so on, in the order the studio attaches them. At most 16.

- Say which picture is the person, which is the place, and which is the previous frame.
- Say what stays (face, clothes, place) and what this frame changes.
- Write the finished still. English. Quote on-image words. If there is no writing, say the image contains no text.
- Do not describe a camera move or a second moment.
